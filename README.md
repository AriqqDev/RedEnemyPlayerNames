# Red Enemy Player Names

A lightweight World of Warcraft addon that makes **enemy players easy to spot** on the default nameplates.

- **Red enemy player names**, or any color you pick
- **Class colors** as an alternative, so you can see a Mage from a Warrior at a glance
- **Horde / Alliance faction icon** next to enemy player names, with adjustable size
- **Optional hostile NPC name color** (off by default, so mobs stay uncolored)
- **Settings panel with a live preview**

Nothing else about your nameplates is changed: health bars, size, layout and CVars are left to Blizzard and your other addons. Colors are restored exactly when a nameplate is no longer an enemy player.

## Usage

Type `/renp` or `/redenemy`, or open **Options > AddOns > Red Enemy Player Names**.

## Installation

Install from CurseForge, or download the latest release and extract the `RedEnemyPlayerNames` folder into `World of Warcraft\_forever_\Interface\AddOns\`.

If you use another addon that colors nameplate names, such as RedNamesForever, disable it to avoid the two fighting over the color.
