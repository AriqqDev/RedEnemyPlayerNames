# Changelog

## 1.1.0

- New: report bugs from inside the game. Type `/renp bug` or click **Report a bug** in the settings. You get a link that opens the GitHub bug form already filled in: versions, your description, other addons, and the latest error from this addon (from BugSack if you have it, and caught by the addon itself if you don't).

## 1.0.0

First release.

- Enemy player names are colored on the default nameplates: one custom color, or each player's class color.
- Horde/Alliance faction icon next to enemy player names, with adjustable size.
- Optional color for hostile NPC names (off by default).
- Settings panel with a live preview: `/renp` or `/redenemy`, or Options > AddOns.
